# Data Science Course

## About Me

My name is Zoltán Újvári, and I am currently learning data science with the goal of building a strong foundation in the field and expanding my practical skills. I want to use what I learn not only to improve my technical understanding but also to support my academic work, including my thesis.

I am especially interested in developing the knowledge and confidence needed to approach data-related problems in a structured and meaningful way. My aim is to understand how to analyze information, interpret results, and apply research methods appropriately to different kinds of problems.

## What I Expect from the Course

I expect this course to help me:

- build a stable and reliable understanding of the basics of data science
- learn how to choose appropriate research methods for a given problem
- improve my ability to start and develop new data science projects
- strengthen my analytical and problem-solving skills
- gain practical experience that can be applied in academic and professional settings

## Learning Goals

By the end of the course, I hope to have:

- a strong knowledge base in core data science concepts
- the ability to formulate research questions and select suitable methods
- confidence in beginning new projects and applying what I have learned
- a better understanding of how data analysis supports real-world decision-making

## Purpose of This Repository

This repository will serve as a place to store notes, exercises, experiments, and project work related to my data science learning journey.
